## Post-Processing

Apply these filters to match the cinematic look:
- Contrast: +15%
- Brightness: -10%
- Saturation: -10%
- Shadows: Shift toward teal (#00d9ff)
- Add subtle vignette

## Optimization

Before placing images, compress them:
- Use TinyPNG (tinypng.com) or Squoosh (squoosh.app)
- Target: JPG at 85% quality
- PNG for transparent images (map glow)

## Currently Using Placeholders

Components are configured to use external Unsplash placeholders until you download the images.
Once downloaded and optimized, place them in the directories above.
